Infraestrutura, DevOps, Redes e Banco de Dados

Este módulo aborda o ecossistema onde o software reside, como ele é implantado e as camadas de comunicação e persistência que garantem sua disponibilidade e performance.

1. DevOps e CI/CD

Cultura e práticas que unem o desenvolvimento (Dev) e as operações (Ops) para acelerar a entrega de software com qualidade.

  • CI (Continuous Integration): Automação da integração de código de vários desenvolvedores, incluindo testes automáticos a cada novo commit.
  • CD (Continuous Delivery/Deployment): Automação da entrega do software em ambientes de homologação ou produção, garantindo que o sistema esteja sempre pronto para ser lançado.

2. Conteinerização e Orquestração

Tecnologias que isolam o software do ambiente físico, garantindo que ele rode da mesma forma em qualquer lugar.

  • Docker: Permite criar contêineres que empacotam o código e todas as suas dependências.
  • Kubernetes (K8s): Ferramenta de orquestração que gerencia milhares de contêineres, lidando com escalabilidade automática, disponibilidade e atualizações sem interrupção.

3. Observabilidade

A capacidade de entender o estado interno de um sistema complexo a partir dos dados que ele gera externamente. Baseia-se em três pilares:

  • Métricas: Dados numéricos ao longo do tempo (ex: uso de CPU, tempo de resposta).
  • Logs: Registros de eventos específicos que ocorreram no sistema.
  • Tracing: Rastreamento do caminho de uma requisição através de vários microserviços.

4. Bancos de Dados e SQL

Onde a informação é armazenada de forma persistente e estruturada.

  • SQL (Relacional): Utiliza tabelas e esquemas rígidos (ex: PostgreSQL, MySQL, SQL Server). Ideal para dados com relações complexas e necessidade de consistência absoluta.
  • NoSQL (Não-Relacional): Flexível, focado em alta escala e diferentes formatos de dados, como documentos (MongoDB), chave-valor (Redis) ou grafos (Neo4j).

5. Redes e Protocolos

A infraestrutura de comunicação que permite que os sistemas se comuniquem.

  • TCP/IP: Conjunto de protocolos fundamental da Internet; o TCP garante que os dados cheguem na ordem correta e sem erros.
  • HTTP/HTTPS: Protocolos de transferência de hipertexto. O HTTPS adiciona uma camada de criptografia (SSL/TLS), essencial para a segurança dos dados trafegados na web.
  • DNS: Sistema que traduz nomes de domínios (ex: google.com) em endereços IP.

6. Computação em Nuvem (Cloud Computing)

Entrega de serviços de computação (servidores, armazenamento e bancos de dados) sob demanda via internet.

  • Provedores Principais: AWS (Amazon), Google Cloud (GCP) e Microsoft Azure.
  • IaaS: Infraestrutura como serviço (máquinas virtuais).
  • PaaS: Plataforma como serviço (foco apenas no código, a nuvem cuida do servidor).
  • SaaS: Software como serviço (aplicações prontas para uso).
